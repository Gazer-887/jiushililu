# 知识提纯

## 定位

一段对话/工作结束时，把**过程中产生的、下次还能用的东西**捞出来——不捞就丢。提炼的目标不是"记流水账"，是**让下次遇到同类事时不用从零开始**。

## 四类内容（识别特征与归档格式）

| 类别 | 识别特征 | 存档格式 |
|---|---|---|
| **决策** | "选了 X"、"决定用 Y"、方案对比 | `### D-编号 — 决策标题`：选了什么、为什么、放弃了什么 |
| **经验** | 踩坑、"以后要"、教训、最佳实践 | `### L-编号 — 经验标题`：现象、根因、下次怎么办 |
| **知识** | "发现"、"原来"、工具用法、配置技巧 | `### K-编号 — 知识标题`：事实本身 + 出处 |
| **模式** | 可复用的流程："先做 X 再做 Y" | `### M-编号 — 模式标题`：步骤 + 适用条件 |

## 流程

1. **扫过程**：回看这段对话/工作，按四类扫描
2. **只提"可复用"的**：一次性的事实（"今天装了某依赖"）不提；带普适性的才提
3. **去重合并**：先查已有存档——已有相近条目就**合并或更新**，不新增重复项（重复的档案库比没有更糟：你会信错旧的）
4. **写清出处**：每个条目带上"从哪来"（哪次任务/哪个错误），方便日后回溯验证

## 反模式

- **什么都记** —— 档案库被流水账淹没，等于没有
- **只记结论不记理由** —— "选了 X"没记"为什么"，下次条件变了没法判断还适不适用
- **不敢改旧条目** —— 新证据推翻旧经验时，更新旧条目并注明，而不是另起一条
